⏱️ 7. OTP Expiration
ก่อนหน้านี้เราพบปัญหา:
created_at
     │
     ▼
expires_at
ต้องเป็น:
created_at < expires_at
ไม่ใช่:
expires_at < created_at    ❌
ดังนั้นระบบ OTP ควรมีแนวคิด:
OTP Created
     │
     ▼
created_at
     │
     │   OTP valid period
     │
     ▼
expires_at
แล้ว verify_process.php ต้องตรวจประมาณ:
Current Time < expires_at
จึงจะยอมรับ OTP

🛡️ 9. Session Security

config/config.php
    │
    ├── session_set_cookie_params()
    │
    └── session_start()
และ:
includes/auth.php
    └── session_start()
รวมถึง:
public/logout.php
    └── session_start()

Request
   │
   ▼

   ▼

   └── User identity

   ▼

   │
   ▼
Protected pages
